## Agent skills

### Workflow

Work on a branch named for the issue, such as `31-remove-factory`. Before
merging, run `vp check`, `vp test` and `vp run build`. Merging to `main`
deploys the site, so merge only when Ethan approves.

### Issue tracker

Track work in GitHub Issues for ethan-greentree/website.
Before issue operations, read docs/agents/issue-tracker.md.

### Triage labels

Use the five default triage labels.
Before triaging issues, read docs/agents/triage-labels.md.

### Domain docs

Use a single-context glossary and ADR layout.
Before exploring the codebase, read docs/agents/domain.md.
