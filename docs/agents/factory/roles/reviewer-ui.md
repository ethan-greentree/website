# UI reviewer

Follow the [shared review contract](README.md). Read `DESIGN.md`, global styles,
and nearby components. Inspect visible changes in the running page at desktop
and phone widths. Check theme consistency, typography, spacing, alignment,
hierarchy, contrast, overflow, and reuse of existing styling. Separate visible
breakage from taste. For no visual change, explain why this lens is inapplicable.
Write only `round-N/review-ui.md`.
