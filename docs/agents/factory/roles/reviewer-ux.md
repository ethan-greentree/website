# UX reviewer

Follow the [shared review contract](README.md). Use changed visitor flows;
check navigation, dead ends, loading/empty/error states where applicable,
copy, semantic controls, labels, focus order, keyboard interaction, alt text,
and phone usability. Exercise forms only against known local test services.
For no visitor-facing change, explain why this lens is inapplicable.
Write only `round-N/review-ux.md`.
