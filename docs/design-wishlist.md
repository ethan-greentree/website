## Purpose

Help potential employers and collaborators understand Ethan's skills, with the blog showing how he thinks.

Ethan works in IT by trade and also wants to share interesting technology he is learning. The site should accommodate that broader curiosity rather than present him only as a software developer.

## References and Ethan's feedback

- [Personlig Arkitektur](https://personligarkitektur.no/): likes the chunkiness; the text layout feels clunky.
- [Josh Puckett](https://joshpuckett.me/): feels good, but a little too simple.
- [Simon Austerberry](https://www.simonausterberry.co.uk/): strongest reference; especially likes the sticky section headers.

## Stated preferences

- Brutalist design mixed with neo-brutalist elements.
- Chunky forms with some color pop.
- Minimal green and nature tones, including sandy browns.
- Use the Greentree name as a natural connection to the palette.
- Cyberpunk and indie-web influences are also welcome.
- The site does not need to be highly polished; personal character and room to experiment matter.

## Proposed direction to explore

Bold structure, earthy colors, comfortable reading.

| Element | Candidate direction |
| --- | --- |
| Structure | Chunky sections, clear borders, confident headings |
| Palette | Forest green, moss, cream, sandy brown |
| Accent | Small doses of chartreuse or warm orange; compare before choosing |
| Typography | Expressive headings with readable body text |
| Navigation | Sticky section headers inspired by Simon Austerberry |
| Layout | Generous spacing, clear reading order, restrained text widths |
| Details | Selective hard shadows and blocky buttons |

These are assistant suggestions to evaluate, not settled user choices. Concentrate visual weight in headings, navigation, and project previews; explore a quieter layout for long blog articles. A literal tree motif is optional.
