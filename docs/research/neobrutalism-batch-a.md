# Neobrutalism research — batch A

Checked 2026-10-11. Ten distinct live reference candidates, not a traffic ranking or proof of “ten most popular.” Primary pages establish identity/content and current destination; style labels below remain provisional until the central screenshot review. Text retrieval does not establish fonts, colors, borders, motion, or mobile behavior. No browser screenshots were captured by this researcher.

The aim is to inform Ethan's design, including his newer dither/night imagery interests, rather than force every reference into a green card template. “Borrow” and “avoid” are design recommendations. Where visual details are undocumented, they are questions for screenshot review rather than invented observations.

## 1. Gumroad

The current page has a concise income-oriented headline, primary selling CTA, marketplace search, illustrated feature sections, testimonials, and product categories. Its image descriptions identify decorative coins and feature illustrations. [Primary homepage](https://gumroad.com/)

**Borrow:** give Ethan a clear introduction and then distinct evidence sections; use one strong illustration/image rather than a generic icon in every card. **Avoid:** copying the sales funnel, income counters, testimonial placeholders, or inventing marketplace-style content. **Visual review:** confirm current display/body typography, pink/yellow color-block rhythm, hard borders and button shadows rather than relying on its famous older screenshots. Classification: **core neo candidate**, not yet visually verified here.

## 2. Panda CSS

Official content mixes a headline and documentation/search navigation with code, features, mascot imagery, installation steps, and framework compatibility. The homepage explicitly identifies the Chakra team. [Homepage](https://panda-css.com/)

**Borrow:** technical substance can supply composition: a real code excerpt, command, diagram, or annotated screenshot communicates more than three invented feature cards. **Avoid:** importing a SaaS feature matrix or changing Ethan's existing stack to Panda merely because its site is attractive. **Visual review:** type hierarchy between code and headings, grid/divider behavior, accent concentration, and treatment of the panda illustrations. Classification: **developer-site neo-adjacent candidate** until current visual evidence is inspected.

## 3. Neobrutalism.dev

The homepage is explicitly a neobrutalist component collection, and the linked source describes Tailwind components. It is a useful source for component mechanics rather than a finished personal-site composition. [Homepage](https://www.neobrutalism.dev/), [source](https://github.com/ekmas/neobrutalism-components)

**Borrow:** inspect how one button or menu combines border, offset shadow, pressed state, and focus treatment; then implement only the necessary pattern in Astro. **Avoid:** pasting the entire component catalogue into a portfolio or assuming component styling supplies an editorial identity. **Visual review:** current examples, heading/body balance, accent palette, and how interactive states preserve alignment. Classification: **explicit neo kit/reference**; current maintenance and compatibility not audited.

## 4. Neobrutalism.com

The current product page describes retro UI components for React and exposes many interface examples. Navigation includes components, blocks, templates, themes, a Figma kit, and paid promotion. [Primary product page](https://neobrutalism.com/)

**Borrow:** study a small number of stateful controls and the relationship between an outline and its hard shadow; document exact state behavior after visual review. **Avoid:** adopting its commercial blocks as the site's content model, assuming everything shown is free, or treating a React catalogue as required Astro infrastructure. **Visual review:** distinguish actual current component examples from marketing decoration. Classification: **explicit neo component system**, useful alongside genuine product and personal sites rather than replacing them.

## 5. Tony's Chocolonely US

The global first-party selector links the US storefront. Current US content prioritizes chocolate/custom wrappers, product names/prices, corporate gifting, brand mission, and updates. This destination differs materially from treating the global selector as a storefront. [Global selector](https://tonyschocolonely.com/), [US storefront](https://us.tonyschocolonely.com/)

**Borrow:** a recognizable image/material identity and deliberately unusual typography can make a site memorable without requiring complex widgets. For Ethan, selected dither imagery could perform that role. **Avoid:** borrowing brand assets or turning a technical portfolio into a candy-store palette. **Visual review:** actual typefaces, orange/yellow surfaces, product photography integration, and navigation depth. Classification: **core neo candidate**, regional design must be checked.

## 6. Gitingest

The live page centers a repository URL input and an Ingest action, with inclusion/exclusion controls and structured results. Its linked official source displayed approximately 15.9k stars; the homepage's retrieved star display was zero, illustrating why dynamically loaded counters need careful interpretation. [Application](https://gitingest.com/), [source](https://github.com/coderamp-labs/gitingest)

**Borrow:** one dominant task, direct labels, and structured technical output. Ethan's article pages should likewise prioritize reading instead of decorative dashboard furniture. **Avoid:** fake command controls or form-like boxes that do nothing. **Visual review:** typography, field/control outlines, shadow and background treatment, and mobile control density. Classification: **neo-adjacent functional devtool candidate**; source popularity does not establish website traffic.

## 7. Cyan Banister

Current first-party text exposes a personal identity and navigation via folder/computer/map/bag image labels, with reading, watching, listening, investing, contact, and shopping destinations. That supports its desktop-metaphor relevance without claiming the researcher operated its windows. [Primary site](https://cyanbanister.com/)

**Borrow:** personal interests and recognizable visual objects can supply character beyond generic cards. **Avoid:** hiding Ethan's writing or contact details behind unexplained icons, or adopting a full fake operating system solely because indie-web aesthetics appeal. **Visual review:** pixel artwork, window framing, purple/grid background if still present, labels, focus states, and touch usability. Classification: **retro neo-adjacent personal site**, not a plain hard-shadow template.

## 8. Cards Against Humanity's 99% Off Sale

The live microsite identifies a second campaign, links a prior campaign, repeats sales/navigation language, and refers to 2025 products. Its continued availability does not make the sale current. The official content is intentionally provocative and dense. [Primary campaign](https://www.99percentoffsale.com/)

**Borrow:** a strong editorial premise can drive typography and layout rather than random decorative motifs. **Avoid:** flashing urgency, repeated banners, dense legal copy, or the campaign's tone on a readable professional site. **Visual review:** actual red/yellow contrasts, overscaled type, repeated strips, product imagery, and control framing. Classification: **live historical neo campaign reference**; no present purchasing availability or popularity ranking established.

## 9. Feastables

Current content announces online sales moving to `mrbeast.store` and prominently lists retail stockists. It includes retailer imagery, a store finder, account/shop links, and brand-information pages. This is evidence of a changing site, not permission to silently analyze an old storefront screenshot as current. [Primary homepage](https://feastables.com/)

**Borrow:** a consistent image/brand language may do more work than multiplying UI decorations. **Avoid:** applying snack-brand urgency, subscriptions, or shopping-bag patterns to a personal blog. **Visual review:** whether chunky buttons/sticker graphics survive the current redesign, typography and primary colors, and whether its remaining layout actually fits the study. Classification: **historically associated, current style unverified**; downgrade if screenshots disagree.

## 10. GT Maru

The first-party type specimen exposes weight, size, subfamily, outline, shade, and glow controls. Its text explicitly discusses rounded signage influences, monospaced rhythm, and variable specimens. It is a type demonstration, not a UI kit or a generic portfolio. [Primary specimen](https://gt-maru.com/)

**Borrow:** let typographic personality create a recognizable composition; experiment with Ethan's real name and long article titles before choosing a display font. **Avoid:** using 200px specimen scale for normal content, adding endless effects, or assuming free trial fonts grant production webfont rights. **Visual review:** scrolling composition, color, rounded/mono pairing, and integration of controls with illustrations. Classification: **typographic neo-adjacent reference**.

## Exclusions and cautions

- **Dodonut:** `https://dodonut.com/` currently resolves to [Bejamas](https://bejamas.com/). An old Dodonut screenshot is historical evidence, not a live current example.
- **Butter:** both `butter.us` and `www.butter.us` failed retrieval here. That is a research-tool failure, not proof the site is offline; do not count it without separate verification.
- **Figma:** current primary page retrieved, but older neo-brutalist branding should be identified as historical unless current screenshots support the classification.
- **tldraw:** current canvas-only text retrieval provides insufficient style evidence. Useful interaction design reference, weak evidence for a neo-brutalist marketing-site corpus.
- **Construct:** live game-development site, but no strong style evidence established; excluded rather than shoehorned into the list.
- **byooooob:** retrieval failed; not counted.

## What this batch can support

It supports selecting current capture URLs and specific questions, not inventing measured tokens. The central visual review should record actual type/color/outline/shadow/layout observations and mark which candidates graduate into the final reference set. A grounded system should distinguish content-led composition (Gumroad/Panda/GT Maru), component mechanics (the two libraries), personal metaphor (Cyan), and campaign maximalism (CAH/Feastables/Tony). Combining every motif would recreate the generic “one-prompt” outcome Ethan rejected.
