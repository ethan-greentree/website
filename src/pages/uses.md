The hardware, software and homelab gear I use day to day. Nothing fancy.

## Desk

- **Desktop PC:** Intel Core i9, 16 GB RAM and a dedicated graphics card. It handles everything I do on it without complaint.
- **A large sit-stand desk.** Switching between sitting and standing makes long sessions easier.
- **Dell monitor.** A dependable screen for long days of reading and writing.
- **SteelSeries mouse, keyboard and headset.** A matching set that's comfortable to use all day.
- **Yeti microphone.** Mostly for talking to AI models, and the occasional call.

## AI tools

- **Claude Code and Codex.** I use them together, and they're the main way I get work done.
- **[Handy](https://handy.computer):** local speech-to-text. Talking to AI models is faster than typing, and it runs on my own machine.
- **Obsidian:** my notes. They're plain Markdown files, so AI agents can read and build on them too.
- **Local models.** I've run a few, but they aren't part of my day-to-day setup.

## Development

- **VS Code with Claude Code:** my main editor. Writing code and talking it through happen in the same place.
- **Windows Terminal** with PowerShell, Git Bash and WSL. One window for whichever shell the job needs.
- **Git and GitHub.** So I can see what changed and undo my mistakes.
- **Docker.** This site runs in it, and it keeps a setup the same from one machine to the next.
- **Languages.** TypeScript is what I reach for first, PHP comes up sometimes, and Python is a close second for small automations.

## Homelab

- **An old Lenovo desktop:** an older Intel Core i5, 8 GB RAM and a 512 GB SSD. Nothing fancy, but it's enough to learn by doing.
- **Proxmox.** It lets one old machine run several services side by side.
- **Pi-hole.** It blocks ads and trackers for the whole home network.
- **Tailscale (planned).** So I can reach those services privately from anywhere.

To see what it runs, read about [my homelab project](/projects/homelab/).

## Learning

- **Microsoft Learn.** Where I'm studying for AZ-104.
- **AWS training.** For learning a second cloud alongside Azure.
- **Alison.** Short courses on side topics, such as Prometheus and Grafana.
